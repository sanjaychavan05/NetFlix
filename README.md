# 🎬 CineFlix - Netflix Inspired Streaming Platform

CineFlix is a Netflix-inspired movie streaming web application built using modern web technologies.  
It allows users to browse movies, watch trailers, and experience a responsive streaming-style UI.

---

## 🚀 Features

- 🎥 Hero Section with Movie Trailer
- 🔐 User Authentication (Signup / Login)
- 🎬 Movie Listing Grid
- 📺 Watch Trailer Functionality
- 💾 MySQL Database Integration
- 🌐 Fully Responsive UI
- ⚡ Fast Next.js Frontend

---

## 🛠 Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- Bcrypt Password Hashing

## ⚙️ Installation (Run Locally)

### 1️⃣ Clone Repository

```bash
git clone https://github.com/sanjaychavan05/NetFlix.git
cd NetFlix

Setup Backend
cd backend
npm install


Create .env file:

DATABASE_URL=mysql://root:@localhost:3306/moviedb
JWT_SECRET=your_secret_key


Start backend:

npm start

Setup Frontend

Open new terminal:

cd frontend
npm install
npm run dev


Open in browser:

http://localhost:3000
